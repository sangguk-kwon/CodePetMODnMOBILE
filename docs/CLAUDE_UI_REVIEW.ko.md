# Claude에게 이월하는 UI 검토 과제

- 과제 ID: `CLAUDE-UI-REVIEW`
- 상태: **미완료 / 계속 이월**
- 등록: 2026-11-10, 사용자 지시
- 담당: 나중에 작업하는 Claude. 지금 UI 구현과 검증은 Codex 담당.
- 시작 조건: Claude가 이 과제를 실제로 수행할 수 있을 때. 이 문서는 Claude 자동 호출 지시가 아니다.

## 사용자 의도와 변경 권한

현재 Claude는 다른 작업과 사용량 부족 때문에 UI 구성을 맡지 않는다.
Codex가 현재 기능에 필요한 UI까지 구현·검증한다. Claude는 나중에 실제 화면을 보고
배치·문구·스타일·상호작용을 자신의 판단으로 자유롭게 재구성해도 된다.
사용자는 이를 사전 허용했으므로 취향에 따른 UI 수정마다 다시 허락을 묻지 않는다.
도구 실행·권한 경계·계정 분리·공통 승인 계약의 변경은 UI 검토 완료와 별도 범위로 다룬다.

## 검토 대상

- 참가자 설정의 도구·허용 규칙, 권한/설정 진단, 전체 자동 승인 안내.
- 호출별 승인 카드의 대상·영향·한 번 허용·거부·대기·만료·취소 표현.
- 승인 카드 ▼의 대화별 허용 범위·앱 재시작 유지 안내, 허용 목록 취소 UI와 진행 이력 접기/펼치기·경과시간·실패/결과 미확인 구분. 이번 Codex 자체 검증으로 완료 처리하지 않는다.
- 저장/실패/미지원/다음 실행 적용 안내, 초안 유지, 계정·세션 전환 시 혼동 방지.
- 작은 창·스크롤·긴 명령/경로·키보드 접근·테마 대비와 전체 채팅 화면의 일관성.
- 이 과제가 미완료인 동안 추가되는 관련 UI도 검토 범위에 포함한다.
- 2026-11-11 후속: 공개 중간 설명을 일반 채팅에 순서대로 남기는 배치, 설명 사이의 작업 표시, 최종 답변과의 구분, 기본 접힌 도구 실행 기록도 자유 검토 대상이다. Codex 자체 스크린샷 검증으로 본 과제를 완료 처리하지 않는다.

관련 파일: `src/chat.js`, `src/chat-tool-settings.js`, `src/chat-permissions.js`,
`src/chat.html`, `src/chat.css`. 구현이 분리되면 새 UI 파일도 여기에 기록한다.

2026-11-10 PR #18 후속: Codex가 Claude 호출별 승인 카드와 공통 규칙 설정·진단 안내를
연결하고 모의 실행기로 Electron 화면을 검토했다. 이 화면들도 Claude의 추후 검토 대상이며
본 과제는 계속 미완료다. 화면 검토 시 CLI 요청에만 적용되는 규칙과 시작 폴더의 의미,
전체 자동 승인과의 차이, 기존 CLI 정책이 먼저 결정할 수 있음을 사용자가 이해하는지 살펴본다.

## 이월과 완료 규칙

2026-11-11 실행 환경 분리 1차: Codex 자동 승인/실행 환경 선택, 기존 제한 없는 설정의
표시, 저장 실패 복원과 미저장 규칙 보호도 추후 검토 대상에 추가한다. Codex가 Electron
화면을 확인한 결과는 본 과제의 완료 근거가 아니며 계속 미완료다.

1. 후속 작업마다 STATUS의 현재 이월 과제에 이 ID·링크·미완료 상태를 유지한다.
2. PR 병합·릴리스·Codex 자체 UI 검증은 이 과제를 완료하지 않는다.
3. 시간이 지나거나 다른 기능이 완료됐다는 이유로 목록에서 제거하지 않는다.
4. Claude가 실제 화면을 검토한 날짜, 검토 범위, 변경 내용 또는 변경 불필요 판단,
   검증 근거와 커밋/PR을 여기에 기록한 뒤에만 완료 처리한다.
5. 검토가 일부만 끝났으면 남은 범위를 적고 계속 미완료로 이월한다.

## 완료 기록

아직 없음. Codex의 구현·검증 결과는 해당 작업의 STATUS에 기록하며 Claude 검토와 구분한다.
