# Claude HD sprite sources

Generated with the built-in image_gen tool, referencing the existing Claude emoticon sheet. The tool returned 1024x1536 PNGs with genuine alpha for all panels. Source cells are usually 256 pixels wide (review: 512), compared with 128 in the old 8-column sheet. Output is a lossless 3072x4576 PNG; output dimensions include resampling and do not imply 4K native detail in each character.

Rebuild: `node scripts/generate-claude-pet.js` (Node 22.23.4). Source indices are explicitly curated in the generator because generated frame counts differ from the request: reactions has four happy poses, with one repeated on the return of the loop. Activity has eight waiting/eight working poses. Six review poses were generated separately. Gaze frames are distinct but exact sixteen-direction pupil accuracy still needs user review.

Packing detects transparent separators between uneven rows, discards detached neighbour strips, rejects clipped main characters, and gives each destination frame 24-pixel gutters. All nine states and sixteen look slots remain. Original/source assets are AI-generated. No upstream assets or license notices are changed.
